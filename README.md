## Data Notes

A small example of a data-analysis workflow:

```python
import pandas as pd
from sklearn.linear_model import LinearRegression

x = data[["input"]]
y = data["outcome"]
model = LinearRegression().fit(x, y)
predictions = model.predict(x)
```

**Linear regression** — model a relationship between an input and an outcome:

$$
\hat{y} = \beta_0 + \beta_1 x + \varepsilon
$$

**Mean** — summarize a dataset with its average value:

$$
\bar{x} = \frac{1}{n} \sum_{i=1}^{n} x_i
$$

`input → outcome` · `observe → model → interpret`
